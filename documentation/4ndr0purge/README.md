# 4ndr0Purge · v1.0.2

> One-click session annihilation — `privacy & security` family · [suite 4ndr0666tools](../INDEX.md)

## Mission

4ndr0Purge is the suite's scorched-earth reset button: a single menu command that destroys the current site's entire client-side session — cookies, localStorage, sessionStorage, IndexedDB, cache storage, and any registered service worker. Use it when a site has poisoned its own state (broken paywall counters, hostile A/B flags, wedged SPAs, dead SW caches) and a plain refresh is not enough. It is deliberately universal and deliberately dumb: no allowlists, no confirmation dialogs beyond the manager's own menu click — the operator asked for a nuke, so it nukes.
