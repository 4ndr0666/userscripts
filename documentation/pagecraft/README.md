## Mission

PageCraft is the every-page utility belt: bulk checkbox control with range and alt-hover selection (de-jQueryed from the legacy implementation), broken-image auto-repair with cache-busting and frame broadcast, a hover-collapse image I/O governor, and Brave infinite scroll. One engine, one glass settings console, zero runtime dependencies — built on the suite kernel (brand/core/glass/store/hotkeys) at document-start, with the console as the intended display for all module state.
