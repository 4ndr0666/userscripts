# Zai Exporter · v1.0.0

> Z.ai conversation exfiltration — `sovereign platforms` family · [suite 4ndr0666tools](../INDEX.md)

## Mission

Zai Exporter turns the Z.ai GLM web chat into an artifact you own: one click on the Ψ HUD button (or the manager menu command) scrapes the live conversation from the page and hands it over as Markdown, JSON, or plain text — code blocks fenced, roles classified, metadata stamped. The engine runs a strict strategy ladder (message-attribute mining, chat-region harvest, degraded plain-text sweep) and always reports which strategy produced the export and how many roles were classified, because a hostile third-party DOM is a versioned surface we do not control — a degraded export says so in the panel and in the artifact header rather than silently pretending a guess is ground truth. It is deliberately the quietest tool in the suite: zero polling, zero observers, zero network, zero HTML-string sinks — the conversation is read from the DOM the operator is already looking at, nothing phones home.

## Feature Inventory

- One-click conversation export to Markdown / JSON / plain text (Ψ HUD button + manager menu)
- Strategy-ladder extraction: attribute mining → chat-region harvest → degraded text sweep, with the chosen strategy reported
- Role classification with explicit attribute ground-truth first, stem heuristics second, alternation repair third — unknown roles stay honest as UNKNOWN
- Code-block preservation (pre → fenced blocks) in Markdown and JSON exports
- Metadata header (title, URL, timestamp, message count) — toggleable, persisted
- Copy-to-clipboard transport (GM clipboard with page fallback) alongside file download
