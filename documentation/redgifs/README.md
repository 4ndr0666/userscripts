# Redgifs++ · v5.2

> Redgifs cinematic integration — `video & players` family · [suite 4ndr0666tools](../INDEX.md)

## Mission

Redgifs++ intercepts Redgifs links on Reddit and renders them in a cinematic overlay instead of the site's chrome; on Redgifs itself it enters a focused video-only mode. For direct /watch/ loads before SPA hydration it falls back to JSON.parse interception — the reliable path when the DOM has not caught up to the router yet.
