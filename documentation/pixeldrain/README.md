# Pixeldrain++ · v1.1.2

> Pixeldrain acquisition, parallelized — `media & links` family · [suite 4ndr0666tools](../INDEX.md)

## Mission

Pixeldrain++ multiplies pixeldrain downloads: multi-proxy parallel transport, streaming, adaptive chunking, and aria2c handoff. The pseudo-QR decoration of the legacy line was replaced by a real RS/mask QR encoder (tools/qr-verify.mjs round-trips it — Gate QR), and every surface is 3lectric-Glass compliant.
